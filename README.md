# Voxel Stand (Minecraft 1.21.1 NeoForge)

Официальный репозиторий главного мода **Voxel Stand**: воксельная ковка, 3D-кастомизация оружия, брони и инструментов, динамические RPG-характеристики и голограммы чертежей.

## Ключевые возможности
* **100% Автономность**: Работает без сторонних библиотек.
* **Совместимость с ~800+ модами**:
  * Использование стандартизированных конвенций тегов NeoForge (`#c:ingots`, `#c:gems`, `#c:raw_materials`).
  * Полное отсутствие перезаписи ванильных рецептов (нулевой риск конфликтов в модпаках).
* **Библиотека модовых материалов и динамический колориметр**:
  * Встроенный каталог параметров и плотностей для 50+ металлов и самоцветов популярных модов (Create, Thermal Series, Mekanism, Immersive Engineering, Mythic Metals, Undergarden и др.).
  * Автоматический динамический сэмплинг цвета центрального пикселя спрайта для абсолютно любых слитков и самоцветов из сотен модов!
* **Нарезчик пластин (Plate Crafter)**:
  * Анимированный верстак с вращающимся точилом и высеканием искр.
  * Нарезка пластин различных размеров: от `16x16` (128 вокселей) до `4x4` (8 вокселей).
* **Изучение качества пластин через подзорную трубу (Spyglass)**:
  * Пластины нарезаются неисследованными.
  * Игрок берет подзорную трубу в левую руку, пластину в правую и зажимает ПКМ: каждые 20 тиков (1 сек) пластина исследуется и падает под ноги:
    * **75% Обычная** (множитель 1.0x) — мягкий стук кузнечного стола.
    * **20% Крепкая** (+15% ко всем характеристикам, включая броню и твердость) — звон наковальни и колокольчика.
    * **5% Чистая** (+30% пик мастерства ко всем характеристикам) — переливающийся звон опыта, кузнечного стола и золотого колокольчика.
* **Чертежи и голограммы**:
  * Сохранение воксельных моделей в файлы чертежей (`config/customsmith/blueprints/<name>.json`).
  * Проекция чертежа на стапель в виде полупрозрачной 3D-голограммы (`alpha = 0.7`) в режиме выживания.
  * Быстрая загрузка и выдача готовых предметов в креативе.
* **Команды мода**:
  * `/voxelstand save <name>` — сохранить модель со стапеля в чертеж.
  * `/voxelstand ghost <name>` — включить голограмму чертежа (alpha 0.7) для крафта в выживании.
  * `/voxelstand load <name>` — загрузить чертеж на стапель (креатив).
  * `/voxelstand give <name>` — выдать готовый предмет из чертежа в инвентарь (креатив).
  * `/voxelstand clear` — отключить голограмму.
  * `/voxelstand list` — список всех сохраненных файлов чертежей.
  * Поддерживаются алиасы `/vs` и `/customsmith`.

## Сборка
* **Minecraft**: 1.21.1
* **NeoForge**: 21.1.264+
* **Java Toolchain**: Java 21
* Сборка проекта:
```bash
./gradlew build
```
Готовый JAR-файл создается в папке `build/libs/`.
